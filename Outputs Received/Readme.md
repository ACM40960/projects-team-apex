## Files

| File | Contents |
|:---|:---|
| [`results.json`](results.json) | **Single source of truth** for every number quoted on the poster and in the README: base classifier metrics, per-method conformal summary stats (coverage/set-size/singleton, mean ± sd over 100 trials), class-conditional and Mondrian coverage, decision-curve data, reliability/ECE data, and the config values used to produce them. |
| [`conformal_results.png`](conformal_results.png) | Two-panel figure: coverage histograms for LAC/APS/RAPS over 100 resampling trials (with the target coverage line), and mean set size ± sd per method. |
| [`fig_classcond.png`](fig_classcond.png) | **Headline figure.** Marginal vs. Mondrian coverage per class: shows marginal conformal under-covering malignant cases (~0.89) and Mondrian per-class calibration restoring it (~0.96). |
| [`fig_decision_curve.png`](fig_decision_curve.png) | Singleton rate and coverage swept across α (0.01–0.30): the automation-vs-guarantee tradeoff curve. |
| [`fig_examples.png`](fig_examples.png) | Three real mammograms (confident benign, confident malignant, ambiguous) with their prediction sets overlaid: makes "set size 1 vs 2" concrete. |
| [`fig_reliability.png`](fig_reliability.png) | Reliability diagram for the raw classifier's softmax confidence (ECE ≈ 0.205): shows the model is poorly calibrated on its own, which is why the conformal layer is needed. |
